### 🔗 Key Navigation Points

#### From Homepage:
- **Header**: All main pages, Help, Settings (if authenticated)
- **Hero Section**: Sign Up, Dashboard (if authenticated)
- **Features Section**: Links to Dashboard, Blast Radius
- **Insights Section**: Links to Activity and Team Insights
- **Footer**: Complete site map with all pages organized by category

#### From Dashboard (`/app`):
- **Sidebar**: Profile, Settings links
- **Navigation**: Can return to homepage

#### From Profile (`/profile`):
- **Header**: Settings link, Back to Dashboard
- **Footer**: Links to other pages

#### From Settings (`/settings`):
- **Header**: Back to Dashboard
- **Tabs**: Account, Security, Notifications, Preferences, Data & Privacy

#### From Help (`/help`):
- **Header**: Back to Home
- **Content**: FAQ sections with expandable items
- **Footer**: Contact Support link

### 🎯 User Journey Examples

#### New User Journey:
1. Homepage (`/`) → Sign Up (`/signup`) → Onboarding (`/onboarding`) → Dashboard (`/app`)
2. Can access Help (`/help`) at any time from header/footer

#### Authenticated User Journey:
1. Homepage (`/`) → Dashboard (`/app`) → Profile (`/profile`) → Settings (`/settings`)
2. Dashboard → Health (`/health`) → Blast Radius (`/blast-radius`)
3. Dashboard → Insights → Activity (`/insights/activity`) or Team (`/insights/team`)

#### Support Journey:
1. Any page → Help (`/help`) → Contact Support (`/grievance`)
2. Footer → Contact Support (`/grievance`)
